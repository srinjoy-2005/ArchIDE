# Changelog: October 23, 2026

## Author: Srinjoy

### 1. Webapp PyTorch AST Decompiler Integration & Two-Way Code Sync (Fixes #28)
- **/api/decompile Endpoint**: Added FastAPI endpoint in `backend/main.py` exposing `PyTorchASTDecompiler` and `AgentGraphCompiler` to decompile Python source into visual graphs (`.arch`) and Agentic IR (`.ir.json`), supporting multi-class architectures, topological auto-layout, and shape validation.
- **Bi-directional Code Editor**: Overhauled `src/components/CentralCodeEditor.tsx` with an interactive, editable code surface supporting line numbers, 4-space tab indentation, and `Ctrl+Enter` decompile shortcut.
- **Decompiler Indicators & Tooltips**: Added an active decompiler badge and informative hover tooltip explaining how AST decompiler converts `nn.Module` code into visual canvas blocks.
- **Real-Time VFS Sync**: Added `updateFileCode` in `src/lib/vfsStore.ts` and wired decompiler results directly into `overwriteFilesFromVFS` with an "Open Graph Tab" button upon successful decompile.
- **Graph Bugfix**: Fixed missing connection between `final_norm` and `prediction_head` in `workspace/ir/main.ir.json` and `workspace/graphs/main.arch`, resolving dangling predictionHead and output branches.
- **API Test Verification**: Added end-to-end asynchronous test cases in `backend/tests/test_api.py` validating single-class and multi-class decompile responses.
