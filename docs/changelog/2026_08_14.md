# Changelog: August 14, 2026

## Author: Gourav Roy

### 1. Backend Documentation Overhaul
- **Consolidation**: Streamlined `docs/backend/` into 4 authoritative documents: `block_registry_spec.md`, `blocks_status.md`, `compiler_design.md`, and `testing.md`.
- **Eliminated Redundant Drafts**: Removed deprecated draft proposals (`compiler_design_plan.md`, `foundational_blocks_design.md`, `testing_setup.md`).

### 2. Frontend Architecture Documentation
- **Architecture Specification**: Created `docs/frontend/architecture.md` detailing Next.js 14 App Router, uncontrolled React Flow canvas model (`defaultNodes`/`defaultEdges`), `CustomNode.tsx`, `TensorEdge.tsx`, and the Zustand global store (`src/lib/store.ts`).

### 3. Unified Daily Changelogs & Automation Workflow
- **Format Migration**: Transitioned from fragmented author-specific changelog filenames (`YYYY_MM_DD_<author>.md`) to unified daily changelog files (`docs/changelog/YYYY_MM_DD.md`) containing author sections.
- **Merged Historical Records**: Consolidated multi-author entries from July 28 and August 11, 2026 into unified daily files.
- **Developer Sync Tooling**: Created `scripts/sync.py`, `.agents/skills/sync-docs/SKILL.md`, `.agents/rules/session_wrapup.md`, and `.github/workflows/ci.yml`.

### 4. Graph Stability, Variadic Ports & Testing Enhancements
- **Orphan Edge Resilience**: Fixed `KeyError` 500 crashes by filtering out edges referencing deleted nodes in `topological_sort`, `shape_inference_pass`, and `generate_pytorch_code`.
- **Single vs. Variadic Port Rules**: Enforced strict single-connection limits for single-input ports (`Linear`, `Conv2D`, `ReLU`, `Sub.in_a`, etc.) via `isValidConnection` while enabling variadic (`is_list=True`) inputs on `Add`, `Multiply`, `Concat`, and `Output`.
- **Inspector Connected Inputs**: Added real-time upstream tensor tracking in `PropertiesPanel` for multi-input blocks.
- **React Hook Order Fix**: Resolved unconditional hook execution order in `PropertiesPanel`.
- **Expanded Backend Tests**: Added test cases for orphan edge tolerance, variadic Add operations, and multi-tensor return aggregations (16 passing tests).
- **Master Roadmap Overhaul**: Reorganized `docs/TODO.md` into an actionable project checklist.
