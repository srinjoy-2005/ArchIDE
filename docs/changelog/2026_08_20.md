# Changelog: August 20, 2026

## Author: Srinjoy

### 1. Architecture & Drag-and-Drop Editor
- **Multi-File State Support**: Re-architected frontend Zustand store to support switching between multiple `GraphFile` tabs dynamically via `<FileTabBar />`.
- **Dynamic Custom Modules**: Implemented sidebar injection logic that parses all project graphs for `Input`/`Output` nodes to create drag-and-drop custom modules.
- **Topological Compilation Pipeline**: Upgraded backend code generator in `compiler.py` to execute a double-pass Kahn's algorithm (graph-level dependency resolution and node-level sorting) for compiling fully nested architectures into a single script.
- **Unified Request Payloads**: Refactored `models.py` and `main.py` endpoints to securely process recursive graph payloads (`{"main_graph_id": str, "graphs": {"id": GraphData}}`) preserving custom module IDs.

## Author: Gourav Roy

### 1. Custom Modules & Compiler Architecture
- **Dual-Target Compiler-Linker Architecture**: Authored [`docs/backend/custom_modules_architecture.md`](../backend/custom_modules_architecture.md) detailing the architectural decision to adopt a modular Python package target (for incremental compilation, clean namespaces, and debugging) combined with a topological linker target (for standalone single-file `model.py` export).
- **Interface Contract Specification**: Specified formal Interface Signatures (Ports, Hyperparameters, Shape Transfer Functions) to enable $O(1)$ local recompilation and fast inter-module shape inference without re-evaluating child subgraphs.
- **Incremental Caching Strategy**: Designed two-tier content hashing (`interface_hash` vs. `body_hash`) for `.arch_cache/` build cache to optimize live visual canvas re-renders.
- **Master Roadmap & Index Updates**: Updated [`docs/TODO.md`](../TODO.md) with Section 4: "Custom Submodules & Multi-Graph Compilation" checklist and indexed the new specification in [`docs/index.md`](../index.md).
