# Changelog — August 26, 2026

## Author: Sampad

### 🖥️ Feature: OneCompiler-Inspired IDE Layout & Virtual File System (VFS)

Transformed ArchiDE into a developer-centric IDE with a hierarchical File and Folder Explorer, Activity Bar, and synchronized Multi-Tab session management.

**New Components & Capabilities:**

| Component / Module | Path | Responsibility |
|---|---|---|
| **ActivityBar** | `src/components/ActivityBar.tsx` | Far-left 44px icon bar to toggle between **Explorer** (Files & Folders), **Block Library** (Layers & Ops), **Search**, and **Settings**. |
| **FileExplorer** | `src/components/FileExplorer.tsx` | OneCompiler-style directory tree supporting nested folders, files, inline in-place creation/renaming, and contextual hover actions (*New File in Folder*, *New Subfolder*, *Rename*, *Permanent Delete*). |
| **VFS & Tab State** | `src/lib/store.ts` | Extended Zustand store with `folders: Folder[]`, `openTabIds: string[]`, `openTab()`, `closeTab()`, and hierarchical folder/file CRUD actions. |
| **Multi-Tab Strip** | `src/components/DnDCanvas.tsx` | Upgraded `FileTabBar` to display relative folder paths (e.g. `models/attention`, `Main`), active tab indicator, and non-destructive tab closing (`closeTab`). |
| **Layout Shell** | `src/app/page.tsx` | Composed `ActivityBar` and dynamic `LeftSidebar` drawer (switching between `FileExplorer` and `BlockLibrary`). |

**Key Refinements:**
- **Non-Destructive Tab Closing**: Closing a tab (`x`) now hides the tab from the editor strip and switches focus to an adjacent open tab without deleting the file from the Virtual File System. Permanent deletion is strictly performed via the File Explorer.
- **Formal IDE Theme**: Refined typography, crisp 1px borders, subtle `#141414` / `#1e1e1e` dark palettes, and formal folder/file icons.
- **Cross-File Compatibility**: Maintained full backward compatibility with multi-graph compilation, shape inference, and custom module derivation in `Header.tsx` and `BlockLibrary.tsx`.

**Verification:** `npm run build` completed with 0 errors in 2.7s.

## Author: Gourav

### ⚙️ Feature: Submodule Compiler Upgrades, Headless Testing Harness & IDE Project Serialization

Expanded the compiler architecture to support constructor parameter forwarding and true shape propagation across nested submodules, added a headless project loader for automated multi-module testing, and integrated full project import/export serialization.

**New Components & Capabilities:**

| Component / Module | Path | Responsibility |
|---|---|---|
| **Submodule Constructor Parameters** | `backend/compiler.py` | Extracts declared graph parameters (`GraphData.parameters`), synthesizes parameterized `def __init__(self, ...):` signatures, binds constructor arguments to submodule instances, and binds layer parameters to graph parameters. |
| **Submodule Shape Propagation** | `backend/compiler.py` | Runs isolated sub-passes on submodule graphs during shape inference, overriding input nodes with incoming tensor shapes and propagating concrete output shapes downstream. |
| **Headless Project Loader** | `backend/project_loader.py` | Loads single graph JSON files or multi-file project directories (`archide.project.json`, `blocks/*.json`, `main.json`) directly for shape verification and compilation. |
| **Multi-Module Test Fixtures** | `backend/tests/fixtures/` | Created `resnet_project` (Stem Conv, ResBlock with CBR submodules, Global Pool, Classifier) and `transformer_project` (LayerNorm, MLPBlock with `d_model`/`d_ff` parameter forwarding). |
| **Automated PyTorch Execution Tests** | `backend/tests/test_project_loader.py` | Integration tests verifying end-to-end compilation, instantiation, and live tensor forward passes with `torch.randn` inputs. |
| **VFS Serialization & Actions** | `src/lib/store.ts` & `src/components/FileExplorer.tsx` | Added `ArchIDEProject` schema, `exportProjectJson()`, `importProjectJson()`, and toolbar buttons (Save / Open Project) to serialize and restore the full VFS hierarchy. |

**Verification:**
- **Backend**: `pytest backend/tests -v` passed all 19 tests in 3.01s (including live PyTorch model execution).
- **Frontend**: `npm run build` passed with 0 TypeScript/JSX errors.

## Author: Srinjoy

### 🐛 Bug Fix: Compiler Shape Inference Method Signature
- **CustomModuleBlock**: Fixed a Liskov Substitution Principle violation in `backend/compiler.py` where `infer_shapes` parameter `incoming` was renamed to `input_shapes: Dict[str, Tuple]` to match `BaseBlock`.

### 🏗️ Architecture: Dedicated Entry Point for Custom Modules
- **Virtual File System & Store**: Formalized an `entryFileId` in `store.ts` that explicitly tracks the root model (e.g., `Main`), protecting it from deletion and folder-cascading drops.
- **Compiler Payload Target**: Modified `Header.tsx` to explicitly point to the `entryFileId` as the `main_graph_id` during `/api/compile`, rather than whichever tab happens to be active.
- **Block Library Filter**: Prevented `BlockLibrary.tsx` from displaying the root model as a draggable sub-module, ensuring clear hierarchy, and excluded the active file to prevent immediate self-recursion.
- **Explorer Badging**: Added a subtle "Main" badge in `FileExplorer.tsx` and removed the delete button for the designated entry file.
