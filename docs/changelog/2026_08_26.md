# Changelog — August 26, 2026

## Author: Sampad

### 🖥️ Feature: OneCompiler-Inspired IDE Layout & Virtual File System (VFS)

Transformed ArchiDE into a developer-centric IDE with a hierarchical File and Folder Explorer, Activity Bar, and synchronized Multi-Tab session management.

**New Components & Capabilities:**

| Component / Module | Path | Responsibility |
|---|---|---|
| **ActivityBar** | `src/components/ActivityBar.tsx` | Far-left 44px icon bar to toggle between **Explorer** (Files & Folders), **Block Library** (Layers & Ops), **Search**, and **Settings**. |
| **FileExplorer** | `src/components/FileExplorer.tsx` | OneCompiler-style directory tree supporting nested folders, files, inline in-place creation/renaming, and contextual hover actions (*New File in Folder*, *New Subfolder*, *Rename*, *Permanent Delete*). |
| **VFS & Tab State** | `src/lib/store.ts` | Extended Zustand store with `folders: Folder[]`, `openTabIds: string[]`, `openTab()`, `closeTab()`, and hierarchical folder/file CRUD actions. |
| **Multi-Tab Strip** | `src/components/DnDCanvas.tsx` | Upgraded `FileTabBar` to display relative folder paths (e.g. `models/attention`, `Main`), active tab indicator, and non-destructive tab closing (`closeTab`). |
| **Layout Shell** | `src/app/page.tsx` | Composed `ActivityBar` and dynamic `LeftSidebar` drawer (switching between `FileExplorer` and `BlockLibrary`). |

**Key Refinements:**
- **Non-Destructive Tab Closing**: Closing a tab (`x`) now hides the tab from the editor strip and switches focus to an adjacent open tab without deleting the file from the Virtual File System. Permanent deletion is strictly performed via the File Explorer.
- **Formal IDE Theme**: Refined typography, crisp 1px borders, subtle `#141414` / `#1e1e1e` dark palettes, and formal folder/file icons.
- **Cross-File Compatibility**: Maintained full backward compatibility with multi-graph compilation, shape inference, and custom module derivation in `Header.tsx` and `BlockLibrary.tsx`.

**Verification:** `npm run build` completed with 0 errors in 2.7s.
