# 2026-09-11

## Author: Srinjoy

- **Frontend Node & Tooltip Formatting:**
  - Fixed dimension tooltip formatting in `CustomNode.tsx` for multi-input tensor operations (e.g. `Multiply`, `Add`) when inputs contain nested tensor shapes (`number[][]`), rendering each tensor individually bracketed (`[1×3×224×224] × [1×3×224×224]`).
- **Decoupled State Persistence & UI:**
  - Removed the buggy `Mirror Local` toggle and its incoming SSE canvas-overwrite effect from `Header.tsx` and `DnDCanvas.tsx`.
  - Replaced it with two dedicated, decoupled actions: **Save State** and **Load State**, each with an individual folder path input persisted in `localStorage`.
  - Retained continuous live auto-saving (`isSaving` flag): clicking **Save State** initiates continuous debounced syncing of canvas changes to the backend, retaining drag-aware debouncing and stripped graph equality checks from commit `8555355ee4542b471c84eec7e67d3f9729b6e40e`.
- **Backend Storage & True VFS Mirroring:**
  - Anchored path resolution in `backend/storage.py` to `PROJECT_ROOT` (`resolve_dir`), fixing a bug where relative paths (such as `"workspace"`) inadvertently created an extraneous `backend/workspace/` directory.
  - Implemented `mirror_vfs_state` in `backend/storage.py` and connected it to `POST /api/state/save`. The save operation now performs a true 1:1 mirror:
    - Prunes any redundant, deleted, or renamed files in the destination directory that are no longer present in the browser VFS.
    - Cleans up empty parent directories.
    - Writes exact file paths and names (`.arch` JSON, `.py` code, and `archide.toml`).
    - Updates active `workspace_dir` so live node/edge canvas auto-saves target the mirrored directory.
  - Implemented `load_vfs_state` in `backend/storage.py` and connected it to `GET /api/state/load`, returning a unified `{ "files": { [rel_path]: content } }` map.
- **Frontend VFS Exact Path Mapping:**
  - Added `getVFSFilePath` in `src/lib/utils.ts` to compute exact logical relative paths (`graphs/main.arch`, `python/main.py`, `archide.toml`) directly from the folder hierarchy.
  - Added `restoreVFSFromFiles` in `src/lib/vfsStore.ts` to restore exact file and folder hierarchies without name or extension mangling (resolving the `.py.py.py` extension compounding issue).
- **Automated Tests:**
  - Added `test_save_and_load_state` and `test_mirror_vfs_state_and_prune` to `backend/tests/test_api.py` covering multi-file mirroring, exact naming, and redundant file deletion.
