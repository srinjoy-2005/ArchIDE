# Changelog: July 26, 2026
**Author**: Gourav Roy

## 1. Major Architecture Shift: Python Backend Engine
- **FastAPI Migration**: Moved the block definition and compilation logic entirely to a Python backend using FastAPI.
- **Data Models**: Created strong Pydantic schemas in `backend/models.py` (`BlockDef`, `CompileRequest`, `NodeData`) for payload validation.
- **Block Registry**: Abstracted all layer definitions (Linear, Conv2D, Add, Split, ReLU, etc.) into `backend/registry.py`. The frontend now fetches the palette dynamically via `GET /api/blocks`.
- **PyTorch Compiler (`backend/compiler.py`)**:
  - Implemented Kahn's Algorithm for topological graph sorting, complete with cycle detection.
  - Built a structural string-generator capable of splitting `nn.Module` creation (`__init__` instantiations) and forward pass operations.
  - Connected `POST /api/compile` to generate fully functional PyTorch models.

## 2. UI Synchronization Fixes
- **Uncontrolled React Flow Refactor**: The `DnDCanvas` was transitioned from controlled `useNodesState` to an **uncontrolled mode** (`defaultNodes` / `defaultEdges`).
- **Properties Panel**: Fixed major state desynchronization issues in `PropertiesPanel` by reading `useNodes().find(n => n.selected)` directly from the internal React Flow store, guaranteeing that parameters can be reliably edited and passed back to the Python backend without overwriting local UI state.
