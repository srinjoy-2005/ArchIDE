# Changelog: September 18, 2026

## Author: Sampad De

### 1. PyTorch AST Decompiler & Multi-Module Roundtrip Pipeline
- **Multi-Input Port Synthesis**: Added `inputs`, `outputs`, `inferredShapes`, and `inferredParams` to `NodeData` in `backend/models.py` with `extra = "allow"` to ensure multi-port connection handles (e.g. `in_2`, `in_3`) are never stripped during Pydantic deserialization.
- **Dynamic Port Resolution**: Updated `_resolve_node_block` in `backend/compiler.py` to dynamically inspect incoming edge target handles and construct missing ports so custom multi-argument submodules (like `MultiheadAttention`, `GatedFusion`, `AttentionPool`) map positional and keyword inputs cleanly.
- **Submodule Code Generation**: Enhanced `CustomModuleBlock` and `GenericCustomModuleBlock` forward code emission to format multi-input argument lists (`self.fusion(attention_features, x_input)`, `self.attention(q, k, v)`).
- **Subscript & Indexed Submodule Calls**: Added AST decompiler support for `self.layers[i](x)` / `self.blocks[0](x)` and `nn.ModuleList` loop unrolling in `backend/python_decompiler.py`.
- **Tensor Passthrough Methods**: Added zero-node passthrough handling for `.contiguous()`, `.clone()`, `.detach()`, `.to()`, and `.type()`.
- **Expression Evaluation**: Extended `_eval_ast_literal` with `ast.Call` support (e.g., `math.sqrt(d_k)`).
- **IR Edge & Handle Preservation**: Overhauled `decompile_arch_to_ir` in `backend/agent_compiler.py` so semantic input/output handles (`in_a`, `in_b`, `in_2`, `in_3`, `q`, `k`, `v`) are strictly preserved rather than collapsed to `in`/`out`, preventing corruption when exporting visual `.arch` graphs to `.ir.json`.
- **Clean Node Aliasing**: Upgraded alias disambiguation in `decompile_arch_to_ir` to prioritize human-readable node labels (`stem`, `stage1`, `down1`) over generic variables (`x_1`, `x_2`), removing arbitrary length gates.
- **Dynamic Variable Type Inference**: Enhanced `_parse_init` in `backend/python_decompiler.py` to auto-detect `float`, `bool`, `string`, and `shape` types directly from default argument literals.
- **Smart Submodule Resolution**: Added filesystem-aware detection in `python_decompiler.py` to differentiate external modular files (`modules/file2`) from inline/generic custom classes (`MultiheadAttentionPooling`, `GatedFusion`).
- **Automated Test Coverage**: Expanded `backend/tests/test_python_decompiler.py` with end-to-end tests for TransformerBlock, multi-argument GatedFusion/Attention, and residual network architectures (39 tests passing).
