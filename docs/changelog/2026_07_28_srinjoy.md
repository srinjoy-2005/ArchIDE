# Changelog: July 28, 2026
**Author**: Srinjoy

## 1. Compiler Architecture Refactor
- **Object-Oriented Block Definitions**: Migrated from a monolithic `compiler.py` and data-only schemas in `registry.py` to polymorphic IR classes inheriting from `BaseBlock` inside the `backend/blocks` module.
- **Decoupled Responsibilities**: Centralized the schema definition (`definition` property), code generation (`emit_init`, `emit_forward`), and static shape inference logic within each block's class.
- **Static Shape Inference Pipeline**: Prepared a new compiler pipeline (Topological Sort -> Shape Inference -> Code Generation) designed to validate tensor shape compatibility before emitting PyTorch code.

## 2. Shape Error Surfacing & Structured API Response
- **`ShapeError` Exception Class**: Introduced a dedicated `ShapeError` in `compiler.py` that carries `node_id` and `node_label` alongside the error message, enabling the frontend to pinpoint the exact offending node.
- **Activated Shape Inference Pass**: `shape_inference_pass()` now runs as the **first step** in `generate_pytorch_code()`. Tensor shapes propagate through the graph in topological order; dimensions with value `"ANY"` bypass strict checks for dynamic/unknown shapes.
- **Structured 422 Response**: `/api/compile` in `main.py` now returns HTTP 422 with a JSON body (`error`, `message`, `node_id`, `node_label`) on shape mismatch, distinct from the generic 400 for graph errors.

## 3. Unique & Readable Variable Names in Generated Code
- **Input Variable Disambiguation (Task A)**: Added `_build_input_var_map()` in `compiler.py` which pre-seeds the variable map for all input nodes before codegen. Duplicate labels are auto-numbered (`x_input`, `x_input_2`, etc.) using a label counter, preventing collision in the `forward()` signature.
- **Semantic Output Variable Names (Task B — `var_hint`)**: Added an optional `var_hint: str` field to `PortDef` in `models.py`. Each block class in `backend/blocks/` now declares a semantic hint on its output ports (e.g. `"sum"` for Add, `"conv_feat"` for Conv2D, `"activated"` for ReLU, `"probs"` for Softmax, `"indices"` for Arange, etc.).
- **`_build_output_var()` Helper**: New compiler helper reads `var_hint` (or a user-supplied `_output_aliases` override from `paramValues`) and disambiguates duplicates graph-wide via a shared `hint_counts` dict, producing names like `conv_feat`, `conv_feat_2`.

## 4. Developer Tooling
- **`run.sh` Fix**: Rewrote the dev launcher script to track child PIDs explicitly, use `SIGTERM` with a grace period before `SIGKILL`, and scope the backend `cd` in a subshell — eliminating the segfault and orphan-port bugs.
- **Port Alignment**: Updated all `localhost:8000` references in `src/app/page.tsx` to `localhost:8001` to match the backend port change.

## 5. Frontend & Documentation TODOs
- **Roadmap Updated**: Added detailed frontend TODO sections in `docs/roadmap_and_features.md` for: shape error highlighting on the React Flow canvas (TODOs 1–5), and user-overridable output variable names from the Properties Panel (TODOs 6–8), including code snippets and backend contract.

## 6. ParamDef Schema Upgrade (Session 2)
- **`read_only` Field**: Added `read_only: bool = False` to `ParamDef` in `models.py`. When `True`, the frontend renders the field as a greyed-out, disabled input with an "inferred" badge — used for tensor shape display.
- **`section` Field**: Added `section: str = "basic"` to `ParamDef` supporting three values — `"shape"` (inferred, read-only), `"basic"` (primary user-editable params), `"advanced"` (collapsible extra PyTorch kwargs).
- **`description` Field**: Added `description: str = ""` to `ParamDef` for tooltip text in the UI.
- **`CheckRequest` Model**: Added a dedicated `CheckRequest` Pydantic model in `models.py` for the `/api/check` endpoint payload.

## 7. Block Definitions Upgraded (Session 2)
- **`LinearBlock` Full Signature**: Added shape params (`input_shape`, `output_shape` as `section="shape"`, `read_only=True`), basic params (`in_features`, `out_features` with `description`), and an advanced param (`bias`). `emit_init` now passes `bias=` to `nn.Linear`.
- **`Conv2DBlock` Full Signature**: Added shape params, full advanced params (`stride`, `padding`, `dilation`, `groups`, `bias`). Fixed shape formula to use the correct PyTorch dilated convolution formula `(H + 2p - d*(k-1) - 1) / s + 1`. `emit_init` now emits the full `nn.Conv2d(...)` signature.
- **`GouravBlock` Removed**: Deleted the test block from `backend/blocks/core.py` and `backend/blocks/__init__.py`.

## 8. `/api/check` Endpoint (Session 2)
- Added `POST /api/check` in `main.py` which runs `shape_inference_pass()` without code generation and returns `{"ok": True, "node_shapes": {...}}`. Returns HTTP 422 with structured `ShapeError` on mismatch.
- `get_blocks()` endpoint switched from returning raw `REGISTRY` to calling `get_all_block_defs()` from the `blocks` package.
