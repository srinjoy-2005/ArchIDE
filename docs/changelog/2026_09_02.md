# September 2, 2026

## Author: Srinjoy Mukherjee

- **Storage Extraction**: Decoupled backend filesystem operations from the VFS router by extracting them into a dedicated API layer `GraphStorage` in `backend/storage.py`. This API abstracts directory handling and file I/O to easily support future database storage integrations.
- **VFS Router Renamed**: Renamed `vfs.py` to `graphVFS.py`, removing all disk logic and delegating endpoints (`/api/vfs/save`, `/api/vfs/init`, and SSE `file_watcher`) to the `storage.py` abstraction.
- **Deterministic UI Syncing**: Fixed an architectural flaw in `DnDCanvas.tsx` auto-save logic that caused infinite SSE feedback loops. 
  - Implemented `getStrippedGraph` to completely strip transient React Flow state (like `selected`, `dragging`, `measured`) before determining if a save is necessary.
  - Implemented drag-aware debouncing: Auto-save is completely suspended while nodes are actively being dragged (`nodes.some(n => n.dragging)`).
  - Maintained a `lastSavedState` equality check to ignore frontend-originated SSE echoes and minor UI interactions.
- **Compiler Naming Convention Comment**: Added a code comment to `compiler.py` clarifying that the `x_` prefix applied to custom variable names guarantees valid Python identifiers and follows PyTorch tensor conventions.

## Author: Gourav

### 1. Variables Feature & Left Sidebar
- **Variable Management**: Fully implemented per-file variable bindings. Added `ArchVariableModel` in the backend and updated the `GraphData` payload to receive variables directly from the VFS. 
- **Compiler Integration**: Updated `compiler.py` to resolve `@var:<name>` string bindings. Variables scoped as `init_param` are injected as `__init__` constructor arguments (e.g., `self.channels = channels`), while `local_const` variables are emitted as module-level constants (e.g., `CHANNELS = ...`).
- **Sidebar UX Revamp**: Repurposed the Activity Bar's placeholder Search tab into a **Variables** tab. Moved the Variables panel out of the Right Inspector into a dedicated Left Sidebar drawer for consistent IDE layout.
- **Drag-and-Drop Binding**: Enabled variables to be dragged from the sidebar and dropped onto parameter inputs in the Properties Inspector. Bound variables are visually represented as distinct pills with an unbind (×) button.
- **Safe Deletion & Compile Guards**: Implemented in-use detection that displays a warning dialog showing affected nodes when attempting to delete a bound variable. 
- **Race Condition Fix**: Ensured the active canvas bindings are stripped directly via React Flow `setNodes()` rather than VFS store manipulation to prevent the debounced auto-save from writing dirty states back to the filesystem. Added a pre-flight payload scan that blocks compilation and displays a code panel error if any nodes contain unresolved (dangling) variable bindings.
