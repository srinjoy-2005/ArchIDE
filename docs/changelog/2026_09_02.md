# September 2, 2026

## Author: Antigravity

- **Storage Extraction**: Decoupled backend filesystem operations from the VFS router by extracting them into a dedicated API layer `GraphStorage` in `backend/storage.py`. This API abstracts directory handling and file I/O to easily support future database storage integrations.
- **VFS Router Renamed**: Renamed `vfs.py` to `graphVFS.py`, removing all disk logic and delegating endpoints (`/api/vfs/save`, `/api/vfs/init`, and SSE `file_watcher`) to the `storage.py` abstraction.
- **Deterministic UI Syncing**: Fixed an architectural flaw in `DnDCanvas.tsx` auto-save logic that caused infinite SSE feedback loops. 
  - Implemented `getStrippedGraph` to completely strip transient React Flow state (like `selected`, `dragging`, `measured`) before determining if a save is necessary.
  - Implemented drag-aware debouncing: Auto-save is completely suspended while nodes are actively being dragged (`nodes.some(n => n.dragging)`).
  - Maintained a `lastSavedState` equality check to ignore frontend-originated SSE echoes and minor UI interactions.
- **Compiler Naming Convention Comment**: Added a code comment to `compiler.py` clarifying that the `x_` prefix applied to custom variable names guarantees valid Python identifiers and follows PyTorch tensor conventions.
