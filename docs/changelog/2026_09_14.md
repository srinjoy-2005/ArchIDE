# Changelog: September 14, 2026

## Author: Srinjoy

### 1. Canvas UX: Stepped Wire Edges (Fixes #16)
- **Orthogonal / Stepped Wire Edges (`SimulIDE` style)**: Added support for orthogonal right-angle wire routing via `getSmoothStepPath({ borderRadius: 0 })` in `src/components/TensorEdge.tsx`, eliminating bezier spaghetti in deep architectures and skip connections.
- **Persistent Routing Mode**: Edge routing defaults to `bezier` for backward compatibility. Added a persistent toggle button on the canvas `<Controls>` toolbar with preference saved to `localStorage` (`'archide_edge_routing'`).
- **Comprehensive Edge Type Mapping**: Mapped all edge type aliases (`tensor`, `default`, `bezier`, `step`, `smoothstep`) in `src/components/DnDCanvas.tsx` to `TensorEdge`. Normalized edges during VFS loading and React Flow mounting so legacy/untyped edges in `.arch` files immediately render as stepped wires when toggled.
- **Live Connection Line Preview**: Configured `connectionLineType` on `<ReactFlow>` to dynamically switch between `SmoothStep` and `Bezier`, reflecting the active routing mode while dragging new connections.

### 2. Configurable Port Orientation & Flipping (Fixes #16)
- **Node Orientation & Flipping**: Added `data.portLayout` support in `src/components/CustomNode.tsx` with `orientation` (`'horizontal'` | `'vertical'`) and `flipped` (`boolean`).
  - In horizontal mode, ports align on Left (inputs) and Right (outputs), inverting when flipped.
  - In vertical mode, ports align on Top (inputs) and Bottom (outputs) with the category accent strip oriented along the top edge.
- **Immediate Layout Synchronization**: Hooked `useUpdateNodeInternals` to trigger upon `portLayout` changes, ensuring React Flow recalculates handle bounds and reroutes connected wires without glitching.
- **Dual Configuration UX**: Added quick-toggle buttons (`ArrowUpDown` / `ArrowRightLeft` and `FlipHorizontal`) directly on the node's hover action toolbar, along with a dedicated "Port Layout" configuration section in `src/components/PropertiesPanel.tsx`.

### 3. Node Variable Badge Clarification (Fixes #16)
- **`var: auto` Indicator**: Replaced ambiguous `→ auto` label on node cards with `var: auto` (or `var: <custom_var>`) and added an informative hover tooltip explaining output variable generation in compiled PyTorch code (`Output variable: auto-generated (x_<id>)`), removing user confusion with parameter auto-inference.

### 4. Canvas-Guarded Tool Shortcuts & Quick Insert (Fixes #16)
- **Canvas-Guarded Single-Key Shortcuts**: Added global canvas keyboard listener in `src/components/DnDCanvas.tsx`, strictly guarded by `isCanvasActive` (focus/hover state) and bypassed when typing in inputs/textareas:
  - `V`: Toggles Variables panel open/closed.
  - `E`: Toggles File Explorer open/closed.
  - `I`: Toggles Inspector open/closed (globally synchronized with `src/components/RightPanel.tsx`).
  - `Tab`: Opens quick layer insertion palette at cursor coordinates.
- **`QuickInsertModal` Palette**: Created `src/components/QuickInsertModal.tsx`, a floating Spotlight-style palette centered at cursor coordinates. Offers instant search across built-in PyTorch blocks and custom modules, with arrow key navigation (`↑`/`↓`), `Enter` to place layer at cursor, and `Esc` to dismiss.

### 5. UI & Tab Bar Cleanups
- **Open Files Tab Bar**: Removed the file creation `+` button from `FileTabBar`, consolidating file creation in the File Explorer.
- **File Explorer Polish**: Removed redundant edge routing toggle from the File Explorer header, keeping routing controls centralized within the canvas viewport.
