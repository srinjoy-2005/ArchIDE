# Changelog: August 30, 2026

## Author: Gourav Roy

### 1. VFS and File Management
- **VFS Folder Restructuring**: Separated JSON graph configurations and generated Python code into standard "graphs/" and "python/" folders in the initial Zustand store state.
- **".arch" Extension Migration**: Updated the default graph file format from ".json" to ".arch" for clearer file type identification.
- **"archide.toml" Support**: Added support for standard project configuration files "archide.toml" at the project root.
- **Dual-View Code Toggle Removal**: Removed the manual "Graph vs Python Code" toggle mode in the canvas toolbar. The active view now conditionally resolves based on the selected file's extension in the "FileExplorer".

### 2. PyTorch Compiler Engine
- **Multi-File Python Output**: Refactored "backend/compiler.py" and "backend/models.py" to support multi-file compilation. "/api/compile" now returns a dictionary mapping graph IDs to PyTorch file content rather than a single concatenated string.
- **Cross-Module Absolute Imports**: Integrated dynamic synthesis of cross-module import paths by accepting and resolving relative paths from the "CompileRequest".
- **Frontend Code Generation Sync**: Implemented "handleCompiledFiles" in "src/lib/store.ts" to consume the compiler's multi-file dictionary output and recursively write ".py" source files to the in-memory "python/" directory.

### 3. Testing
- **Test Infrastructure Upgrade**: Migrated the headless PyTorch execution test suite ("test_project_loader.py") to correctly mock write ".py" files inside a temporary testing directory "tmp_path" to resolve PyTorch internal dynamic module imports.

### 4. Graph Construction and Live Sync
- **Live Sync Core Bridge (VFS)**: Rewrote recursive watcher in `backend/vfs.py`, updated `DnDCanvas.tsx` to push full paths, and updated `store.ts` to dynamically create nested UI folders for mirrored files.
- **Graph Schemas Fixed**: Populated missing React Flow schemas (`type: "custom"`, `type: "tensor"`, `inputs`, `outputs`, `params`) across all `.arch` files.
- **Python Graph Builder SDK**: Added `workspace/archide_builder.py` to allow programmatic, schema-validated `.arch` generation without raw JSON mistakes.
- **Transpose Block**: Added `TransposeBlock` in `backend/blocks/tensor_ops.py` for correct Transformer architecture code generation.
- **Transformer Architecture**: Programmatically generated `transformer_encoder.arch`, `transformer_decoder.arch`, and `main.arch` using the new Transpose block.
- **Agent Editing Constraints**: Created `.agents/skills/archide-graph-editing/SKILL.md` to document strict JSON schemas for modifying `.arch` files.

### 5. Compilation and Frontend Error Fixes
- **LayerNorm Shape Inference Fix**: Patched `backend/compiler.py` to correctly map wildcard parameter defaults `?` during inferred parameter injection, resolving a bug where `LayerNorm` output `[1,]` instead of the inferred `[256,]`.
- **Multi-File Path Resolution**: Fixed a UUID mapping bug in `src/lib/store.ts` (`handleCompiledFiles`) to correctly use full paths as graph IDs and write the compiled Python code to the `python/` directory in the frontend UI.
- **Payload Inspector Fix**: Updated `src/app/dev/payloads/page.tsx` to correctly handle the multi-file `response.files` format instead of the old `response.code`, preventing false-positive 'ERROR' notifications during successful compilations.
