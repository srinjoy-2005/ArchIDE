# Changelog: September 20, 2026

## Author: Gourav Roy

### 1. Core Blocks, Dynamic Shapes & Scalar Operations
- **Dynamic Shape Extractor**: Implemented `ShapeExtractorBlock` in `backend/blocks/core.py` with dedicated outputs (`shape`, `dim_0` to `dim_3`), enabling runtime tensor dimension extraction and dynamic reshape dataflows.
- **New Standard Layers**: Added `GELUBlock`, `SiLUBlock`, `LayerNormBlock`, `BatchNorm1DBlock`, and `EmbeddingBlock` to the core block registry (`backend/blocks/normalization.py`, `backend/blocks/core.py`, `backend/blocks/__init__.py`).
- **Scalar Binary Operations**: Extended `AddBlock` and `MulBlock` in `backend/blocks/tensor_ops.py` with `scalar_a` and `scalar_b` parameters to support arithmetic with constants (e.g. `x + 1`, `x / math.sqrt(d_k)`).
- **Lazy Module Emission**: Added `LAZY` resolution mode to `LinearBlock` and `Conv2DBlock`, emitting `nn.LazyLinear` and `nn.LazyConv2d` to defer dimension inference to runtime.
- **Tuple Parameter Type & Variable Interpolation**: Added `tuple` parameter type in `backend/models.py` and relaxed shape variable interpolation in `backend/compiler.py` so integer/float variables can be embedded within shape tuples (e.g. `(1, @var:channels, 32, 32)`).

### 2. Multi-Class Decompilation & Canonical Benchmark Verification
- **Multi-Class File Decomposition**: Extended `backend/python_decompiler.py` to extract all `nn.Module` classes within a file into individual `.arch` graphs rather than only the final class.
- **Deep Attribute Chains & Submodule Mapping**: Added AST resolution for nested attribute chains (`self.backbone.layer1(x)`) and `nn.ModuleList` loop unrolling.
- **Decompiler CLI Entrypoint**: Added standalone CLI support in `backend/python_decompiler.py` (`python backend/python_decompiler.py <file.py> --output <output.json> --workspace <dir>`).
- **Real-World Benchmark Test Suite**: Created `backend/tests/test_real_world_models.py` with 23 end-to-end roundtrip tests verifying exact numerical equivalence (`torch.allclose` at `atol=1e-4`, max difference `0.0`) across canonical architectures: ResNet (with/without downsampling), ConvNeXt, Transformer MLP, ViT with loop unrolling, UNet with skip concatenation, and multi-class modules.
- **Canonical nanoGPT Benchmark**: Integrated `benchmarks/nanoGPT.py` as an arbitrary real-world benchmark target.
