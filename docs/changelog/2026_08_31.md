# August 31, 2026

## Author: Antigravity

- **Frontend Store Refactoring**: Split the monolithic Zustand store (`store.ts`) into `vfsStore.ts` (Virtual File System state) and `editorStore.ts` (UI state, canvas mode, clipboards) to prevent unnecessary re-renders. Created `types.ts` for centralized type definitions.
- **Frontend Validation**: Introduced `paramTypes.ts` with a `PARAM_TYPE_HANDLERS` registry for strict validation and coercion of `int`, `float`, `bool`, and `string` parameters directly in the UI.
- **Auto-Infer Mechanism**: 
  - Backend: Added an `auto_infer: bool = False` flag to `ParamDef` models, enabling it for `LinearBlock`, `Conv2DBlock`, `BatchNorm2DBlock`, and `LayerNormBlock`.
  - Frontend: `ParamInput` now automatically renders a grayed-out "Auto-Infer" checkbox toggle for these fields instead of exposing raw `-1` integers to the user.
- **Real-time Shape Feedback**: Hitting "Compile Code" now triggers shape inference alongside code generation. The `generate_pytorch_code` API endpoint now returns full tensor shape topologies (`node_shapes`) and dynamically syncs them to the frontend visual layer without destructively overwriting the user's locked auto-infer settings.
