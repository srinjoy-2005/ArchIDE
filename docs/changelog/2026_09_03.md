# 2026-09-03

## Author: Antigravity

- **Compiler Backend:**
  - Added a cleanup step in `backend/main.py` using `shutil.rmtree` to clear the `workspace/python` directory before compilation, preventing stale orphaned files.
  - Added strict bounds checking to `start_dim` and `end_dim` in `FlattenBlock` (`backend/blocks/shape.py`) to raise `ValueError` on out-of-bounds indices, fixing a bug where arbitrary dimensions could be generated.
- **Frontend VFS & Explorer:**
  - Migrated VFS internal paths to use stable UIDs (`graphsFolderId`, `pythonFolderId`) instead of mutable folder names, ensuring graph imports and backend mappings don't break when a user renames root folders (`src/lib/vfsStore.ts`).
  - Added cleanup logic in `vfsStore.ts`'s `handleCompiledFiles` to remove stale generated files from the frontend tree.
  - Disabled manual file creation, folder creation, and renaming inside the compiled `python/` tree (`src/components/FileExplorer.tsx`).
  - Enforced the `.arch` extension for any newly created files inside the `graphs/` tree.
  - Removed default example `res_block.arch` graph to provide users with a clean blank slate on startup.
- **Frontend IDE & Canvas:**
  - Improved `Header.tsx` error handling for `handleCheck` and `handleExport` (Compile) to explicitly delete cached `output_shape` and `input_shape` parameters, preventing the blocks from incorrectly displaying dimensions from a previous successful run during a shape mismatch.
  - Fixed a bug where clicking "Check" with a broken graph failed to highlight the error block red (added `setShapeErrorNodeId`).
  - Fixed a race condition in `DnDCanvas.tsx` where React Flow's internal `onNodesChange` dimension updates would instantly wipe out the red error highlight. The highlight is now only cleared upon explicit structural edits (adding/removing nodes or edges).
  - Implemented a DFS in `BlockLibrary.tsx` to detect and filter out circular dependencies from the custom module list, and restricted the module list to only files within the `graphs/` tree.
  - Added a one-time save trigger in `Header.tsx` to push unsaved in-memory graph files to disk when turning on Mirror Local mode.
