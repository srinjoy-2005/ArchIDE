# Changelog — August 25, 2026

## Author: Srinjoy

### 🏗 Refactor: Modularize `page.tsx` (1255 → 43 lines)

The monolithic `src/app/page.tsx` was broken into 8 focused component files plus a shared constants module. `page.tsx` is now a 43-line layout shell that only imports and composes panels.

**New files created:**

| File | Responsibility |
|---|---|
| `src/lib/constants.ts` | `API_BASE`, `getId()`, `initialNodes/Edges`, `FALLBACK_BLOCKS` |
| `src/components/DnDCanvas.tsx` | React Flow canvas + `FileTabBar` (multi-file tab strip) |
| `src/components/BlockLibrary.tsx` | Left sidebar: `CategoryIcon`, `BlockItem`, search + grouped registry |
| `src/components/Header.tsx` | Top bar: `buildPayload`, `handleExport`, `handleCheck`, `handleReset` |
| `src/components/PropertiesPanel.tsx` | `ParamInput`, `ModelSummaryDashboard`, `PropertiesPanel` |
| `src/components/RightPanel.tsx` | Right panel shell: Inspector / Code tab bar + open/close |
| `src/components/CodePanel.tsx` | Code viewer with copy-to-clipboard and download-as-`model.py` |
| `src/components/DocPanels.tsx` | `DocContextMenu` (right-click popup) + `DocDetailsPanel` (slide-in) |

**Key architectural decisions preserved:**
- `ReactFlow` in `DnDCanvas.tsx` still uses `defaultNodes`/`defaultEdges` (uncontrolled mode) per the guardrail in `.agents/project_context.md`.
- `nodeTypes` and `edgeTypes` remain at **module level** in `DnDCanvas.tsx` to prevent React Flow from unmounting nodes on re-render.
- `BlockLibrary` now owns registry fetch + custom module derivation (previously in `Home`).
- `Header` owns all API communication logic (`buildPayload`, compile, check, reset).

**Verification:** `tsc --noEmit` exits with 0 errors. All 16 backend pytest tests pass.
